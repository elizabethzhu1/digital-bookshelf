# Digital Bookshelf

**[elizabethzhu1.github.io/digital-bookshelf](https://elizabethzhu1.github.io/digital-bookshelf/)**

Make your own bookshelf. You start with empty shelves and a short tour of each part of the page, then:

- **add your books** by searching Open Library (covers, pages and categories fill themselves in) or typing them in
- put them on shelves: reading, to read, finished, set aside, wishlist; open any book to rate it, track your page and keep notes and a review
- **decorate**: houseplants, a candle, a sleeping cat, tea, a globe; wood or metal shelves; covers or spines
- switch **day and night**, drag the hanging **reading lamp** around, watch the **San Francisco window**
- keep a reading **journal**, set a yearly goal, rank your favourites, and get recommendations **for you**

Your library is saved in your own browser, with no account. **Export** (at the bottom of the page) downloads it
as Markdown files that also open in Obsidian, and **Import** brings them back on any device.

See an example: [Liz's bookshelf](https://elizabethzhu1.github.io/bookshelf/).

---

This repo only publishes the site. The code lives in [elizabethzhu1/bookshelf](https://github.com/elizabethzhu1/bookshelf),
